# Machinista OB-Xd patches

32 original patches by Machinista, in four banks of eight: Bass, Keys, Leads, Pads.
Import the JSON banks in Machinista WebUI > Patch banks with OB-Xd selected.
Requires the OB-Xd 2DaT port. These are parameter data, not audio samples.

These original bank JSON files are dedicated to the public domain under
CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/legalcode.en
The OB-Xd implementation retains its existing GPL license; this dedication
applies only to these independently authored bank files.

Revision 2: Oberheim-style brass, PWM strings, comping keys, punch basses,
hard-sync and unison leads. Independently programmed using the legacy DSP
parameter curves, not imported factory-program copies. Validated at 44.1/48 kHz
with single notes and eight-note chords: 64 renders, no clipping or stuck tails.
Reimport these four banks to replace the previous Machinista version; saved
project sounds keep their own parameter values until a patch is loaded again.
